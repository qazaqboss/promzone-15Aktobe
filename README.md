# Промзона 15А · Актобе — сайт-презентация на продажу

Статический сайт (без сборки) для продажи производственной базы 2,949 га за 1,5 млрд ₸.

| Файл | Что это |
|---|---|
| `index.html` | Сайт-презентация: инвест-идея, цифры, калькулятор доходности, сценарии, 3D-модель, состав объекта, локация, контакты |
| `model.html` | Интерактивная 3D-модель базы (three.js, локально в `assets/vendor`) |
| `banner.html` | Шаблон баннера, размер задаётся параметрами: `/banner?w=1200&h=630` |
| `og.png` | Превью для соцсетей/мессенджеров (1200×630) |
| `assets/banner-*.png` | Готовые баннеры: 1920×640 (шапка/реклама), 1080×1080 (пост), 1080×1920 (сторис) |

## Перед публикацией
Заполните контакты продавца в `index.html` — объект `CONTACT` в начале `<script>` (имя, телефон, WhatsApp, Telegram, email). Кнопки появятся автоматически.

## Деплой на Vercel
1. vercel.com → **Add New… → Project** → импортируйте этот репозиторий.
2. Framework Preset: **Other**, Build Command — пусто, Output Directory — `.` (корень).
3. **Deploy**. Каждый push в ветку будет обновлять сайт автоматически.

Или из терминала: `npm i -g vercel && vercel --prod`.
